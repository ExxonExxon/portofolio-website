# Project Overview

This directory contains a personal portfolio website, primarily showcasing web development projects and photography. It's built as a collection of static HTML pages, utilizing modern frontend technologies for styling and interactivity.

## Key Technologies Used:
*   **HTML5:** For structuring the web content.
*   **Tailwind CSS:** A utility-first CSS framework for rapid UI development and responsive design.
*   **JavaScript:** For interactive elements, animations (via AOS), and dynamic content (e.g., typewriter effect, image modals, mobile menu toggling, Formspree integration).
*   **AOS (Animate On Scroll):** A JavaScript library for animating elements as they scroll into view.
*   **Font Awesome:** (Used in `Facebook Clone`) For scalable vector icons.
*   **Formspree:** (Used in `contact.html`) For handling form submissions without a custom backend.

## Directory Structure and Content:

*   **`index.html`**: The main landing page of the portfolio. It introduces the developer, displays selected web projects (Spotify Remake, Simple Wikipedia Page, Facebook Clone), and showcases photography.
*   **`contact.html`**: A dedicated contact page with a form for inquiries, powered by Formspree.
*   **`Assets/`**: Contains various static assets:
    *   `photography-images/`: JPEG images used in the photography gallery section of `index.html`.
    *   `spotify-ui-project-picture.png`: An image likely used as a preview for the Spotify project.
*   **`Facebook Clone/`**: A subdirectory containing a static HTML/CSS/JS representation of a Facebook user interface.
    *   `index.html`: The main file for the Facebook Clone.
    *   `assets/`: Likely contains assets specific to the Facebook Clone (though not explored in detail).
*   **`Spotify Clone/`**: A subdirectory containing a static HTML/CSS/JS representation of a Spotify user interface.
    *   `index.html`: The main file for the Spotify Clone.
    *   `Songs Photos/`: Contains images related to the Spotify Clone.
*   **`Wikipedia Refined/`**: A subdirectory containing a static HTML/CSS representation of a Wikipedia-style page.
    *   `index.html`: The main file for the Wikipedia Refined project.

## Usage:

This project is a static website and can be viewed directly in a web browser.

1.  **Open `index.html`:** To view the main portfolio page, simply open the `index.html` file in any modern web browser.
2.  **Navigate Projects:** Links to individual projects (e.g., "Spotify Clone", "Facebook Clone", "Wikipedia Refined") are available on the `index.html` page and will open their respective `index.html` files.
3.  **Contact Form:** The `contact.html` page features a contact form that utilizes Formspree for submissions.

There are no build steps or complex setup procedures required. The website is designed to be served directly from a web server or viewed locally.
